# Historical numeric-clock validation

These inputs and recorded outputs belong to the earlier raw HHMMSS-integer interpretation. They are retained for traceability, not as physical-second validation. The loader source was subsequently corrected to convert HHMMSS; rebuilding it does not reproduce the unchanged old output tables. The old 20-instance/197-rank statistics must not be attributed to the current seconds-based release.

Current validated inputs, executions and rank comparisons are in ../seconds_instances/. Use ../../scripts/validate_seconds_instances.py from the repository root to reproduce them.
